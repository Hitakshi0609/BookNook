About BookNook

BookNook is a small book review website built as a mini project for my Web Development class using HTML, CSS and JavaScript.

The goal is simple: short, honest reviews that help you pick your next read quickly.

Built with

  • HTML for structure
  • CSS for styling
  • JavaScript for search, filters and form validation
